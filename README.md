# OtzyvTut Review Studio (SEO Safe & Anti-Spam)

Автономная программа сбора, аудита накруток и уникализации отзывов для сайта **otzyvtut.com**.

## Возможности:
1. **Гибкий фильтр активности**:
   - Чекбокс «Только активные компании» (проверяет наличие свежих отзывов 2025–2026 и доступность сайта компании).
   - Чекбокс «Только подозрительная активность» (детектор разрыва рейтингов: накрутка на мягких сайтах против жестких/мошеннических баз moshennik.eu / dou / vnutri).
2. **Управление тональностью**:
   - «Естественный баланс» (как в реальности на площадках)
   - «Только позитив (4★ - 5★)»
   - «Только негатив / критика (1★ - 2★)»
   - «Только нейтральные (3★)»
3. **100% Защита SEO**:
   - Глубокий рерайт через Google Gemini (без дублирования текстов).
   - Автоматическая генерация заголовков, структурированных плюсов и минусов (для Rich Snippets Google со звёздочками).
   - Естественный разброс дат (разносит отзывы в прошлое на дни/недели, исключая спам-всплески).
4. **Безопасный экспорт**:
   - Генерация чистого SQL-пакета для мгновенной вставки в таблицу `wp_reviews` с нужным `company_id`.

## Запуск:
```bash
python3 app.py
```
Открыть в браузере: `http://127.0.0.1:8795`
